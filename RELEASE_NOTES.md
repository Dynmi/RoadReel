# RoadReel 1.0.0

RoadReel is a new open-source macOS viewer for TeslaCam recordings. It combines six synchronized camera views with thumbnails, event-aware navigation, full-screen playback, clip export, and recoverable deletion in a polished bilingual interface.

## Download

- `RoadReel-1.0.0.dmg` — recommended installer image
- `RoadReel-1.0.0-macOS-universal.zip` — portable app archive
- `SHA256SUMS.txt` — download integrity checksums

Requires macOS 14 or later. Both Apple silicon and Intel Macs are supported.

## First launch

This community build is ad-hoc signed and is not Apple-notarized. After copying RoadReel to Applications, Control-click it and choose **Open**. If needed, approve it under **System Settings → Privacy & Security**.

RoadReel is independent software and is not affiliated with Tesla, Inc.
