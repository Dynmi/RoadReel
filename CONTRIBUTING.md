# Contributing to RoadReel

Thanks for helping improve RoadReel.

1. Search existing issues before opening a new one.
2. Fork the repository and create a focused branch.
3. Keep user-facing text available in both Chinese and English.
4. Build the Release configuration and test with a copied TeslaCam sample before submitting.
5. Do not commit private recordings, location data, Xcode user state, or build artifacts.
6. Describe the behavior change and verification performed in the pull request.

By contributing, you agree that your contribution is licensed under the MIT License.
