# Security Policy

## Supported versions

Security fixes are applied to the latest RoadReel release.

## Reporting a vulnerability

Please do not publish a reproducible security issue before it can be addressed. Open a GitHub Security Advisory for this repository and include:

- the affected RoadReel version and macOS version;
- clear reproduction steps;
- the expected and actual behavior;
- any proof-of-concept files that are safe to share.

RoadReel processes untrusted media and metadata from removable drives. Reports involving crafted video files, path traversal, sandbox escape, or unintended file modification are especially useful.
