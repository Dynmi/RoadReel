# Changelog

All notable changes to RoadReel are documented here.

## 1.0.0 — 2026-09-23

- Introduced the RoadReel name and application icon.
- Added Chinese and English first-launch language selection.
- Added six-camera synchronized playback and reliable primary-camera switching.
- Added thumbnails, search, sorting, and event/segment timeline markers.
- Added full-screen playback, variable speed, seeking, and camera context menus.
- Added full-view and ±30-second MP4 export.
- Added recoverable project deletion through macOS Trash.
- Added security-scoped USB folder persistence and stability improvements.
- Added a clear explanation for telemetry unavailable in exported TeslaCam files.
